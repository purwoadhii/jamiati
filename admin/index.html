Simpan semua tulisan tamu

Yang diketik di game (wish di lilin, jawaban "bagaimana keadaanmu", keluh kesah di bangku, dan yang dibuang di tempat sampah) disimpan ke database Supabase milikmu, lalu bisa kamu baca di bawah. Kosongkan Project URL kalau tidak ingin disimpan.

Cara memasang database (sekali saja, ± 5 menit)
  1. Daftar gratis di supabase.com (bisa masuk dengan akun GitHub), lalu klik New project. Isi nama bebas, buat database password (tidak dipakai di sini), pilih region Singapore, lalu tunggu proyeknya siap.
  2. Tulis sandi baca di kolom di bawah (minimal 6 karakter, ingat baik-baik). Klik Buat skrip SQL, lalu Salin skrip.
  3. Di Supabase buka SQL Editor, tempel skripnya, lalu klik Run. Harus muncul "Success".
  4. Buka Project Settings → API Keys (atau tombol Connect). Salin Project URL dan kunci publishable (atau anon public) ke dua kolom di bawah. Jangan pakai kunci secret / service_role.
  5. Klik Kirim tes, lalu Muat tulisan: baris "Tes dari admin" harus muncul. Setelah itu klik Simpan paling bawah.
